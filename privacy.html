개인정보처리방침

시행일: 2026년 10월 14일

대상

ndh-assistant는 앱 소유자 한 사람만 쓰는 개인용 앱입니다. 다른 사람의 Google 계정 데이터는 수집하지 않습니다.

접근하는 데이터

소유자 본인 계정의 Google Calendar 일정과 바쁜 시간 정보를 읽고, 소유자가 승인한 일정을 추가하거나 수정합니다. 사용하는 권한은 calendar.readonly와 calendar.events입니다.

저장과 공유

인증 토큰과 일정 정보는 소유자의 개인 서버에만 저장합니다. 제3자에게 제공하거나 판매하지 않고, 광고에 쓰지 않습니다.

Google API 데이터 사용

Google API에서 받은 정보의 사용은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

삭제

소유자는 Google 계정의 보안 설정에서 언제든 앱 접근 권한을 철회할 수 있고, 서버에 저장된 인증 정보는 그때 삭제합니다.
